# ACM-Notes

ACM 竞赛学习仓库：知识点笔记、做过的题目、解题模板。

## 目录结构

```
notes/       知识点笔记（简介 → 核心思想 → 算法流程 → 复杂度）
problems/    做过的题目（题解、代码）
templates/   通用解题模板（完整可编译的 .cpp）
```

三个目录使用相同的分类：

```
basic            基础算法（排序、二分、贪心）
data-structure   数据结构（线段树、并查集、树状数组）
graph            图论（最短路、最小生成树、网络流）
dp               动态规划（背包、区间DP、树形DP）
string           字符串（KMP、Trie、AC自动机）
math             数学（数论、组合、矩阵快速幂）
geometry         计算几何（凸包、旋转卡壳）
misc             杂项（位运算、博弈论）
```

## 用法

- 学习一个知识点：看 `notes/<分类>/` 下的笔记，刷 `problems/<分类>/` 里的题目，熟悉 `templates/<分类>/` 的模板
- 新增题目：把代码或题解放入 `problems/` 对应分类目录即可，文件名用题号（如 `P3372.cpp`）
- 新增知识点：在三个目录的同名分类下分别添加笔记、题目、模板
