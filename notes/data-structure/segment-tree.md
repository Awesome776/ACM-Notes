# 线段树

## 简介

二叉树形数据结构，维护区间信息（求和、最值等），支持区间修改和区间查询。

## 核心思想

每个节点管辖区间 `[l, r]`，左子 `[l, mid]`、右子 `[mid+1, r]`。区间修改时用**懒标记**延迟子树更新，保证 O(log n)。

## 算法流程

1. **建树**：递归到叶子赋值，回溯时 `pushup` 合并子节点信息
2. **区间修改**（加值）：若当前节点被完全覆盖，直接修改并打懒标记；否则 `pushdown` 下传标记后递归子节点
3. **区间查询**：若完全覆盖直接返回；否则 `pushdown` 后递归查询子节点并合并结果

`pushdown`：将当前节点的懒标记加到子节点的值和懒标记上，然后清除当前节点标记。

## 复杂度

- 建树：O(n)
- 区间修改 / 区间查询：O(log n)
- 空间：O(4n)
