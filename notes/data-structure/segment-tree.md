# 线段树

## 概述

线段树（Segment Tree）是一种二叉树形数据结构，用于维护**区间信息**（求和、最值等）。支持单点修改、区间修改（配合懒标记）和区间查询，时间复杂度均为 O(log n)。

## 基本结构

```
        [1, 4]
       /      \
   [1, 2]      [3, 4]
   /    \      /    \
 [1,1] [2,2] [3,3] [4,4]
```

- 每个节点维护一个区间的信息
- 左子节点：`[l, mid]`，右子节点：`[mid+1, r]`
- 节点编号：根节点为 1，左子 `2*p`，右子 `2*p+1`
- 数组大小：开 `4 * n` 防越界

## 操作

### 建树 `build(p, l, r)`

从叶子节点向上合并区间信息。

### 区间查询 `query(p, l, r, ql, qr)`

将查询区间 `[ql, qr]` 拆分为若干线段树节点覆盖的区间，合并结果。

### 区间修改 + 懒标记 `update(p, l, r, ul, ur, val)`

对区间加值时，使用**懒标记（lazy tag）**延迟子树更新，保证 O(log n) 复杂度。

## 复杂度

| 操作 | 时间 | 空间 |
|------|------|------|
| 建树 | O(n) | O(4n) |
| 区间查询 | O(log n) | — |
| 区间修改 | O(log n) | — |

## 典型应用

- 区间求和 + 区间加（对应模板）
- 区间最值（RMQ）
- 区间赋值（将 lazy tag 改为覆盖式）
- 离散化 + 线段树（值域大时）
- 动态开点线段树（值域 1e9 时）
- 可持久化线段树（主席树）
