# 背包 DP

## 简介

给定容量为 W 的背包和若干物品（重量 w_i，价值 v_i），选择物品使总价值最大。

## 核心思想

定义 `dp[j]` 为容量为 j 时的最大价值。对每个物品，倒序（01 背包）或正序（完全背包）更新。

## 算法流程

### 01 背包（每个物品最多取一次）

1. 初始化 `dp[0..W] = 0`
2. 对每个物品 i：**倒序**遍历 `j` 从 W 到 w_i
3. `dp[j] = max(dp[j], dp[j - w_i] + v_i)`
4. 答案为 `dp[W]`

### 完全背包（每个物品无限取）

与 01 背包的唯一区别：**正序**遍历 `j` 从 w_i 到 W。

## 复杂度

- 时间：O(nW)
- 空间：O(W)（滚动数组优化后）
