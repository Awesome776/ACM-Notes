# 二分查找

## 简介

在单调序列或单调答案上，每次将搜索范围缩小一半，O(log n) 定位目标。

## 核心思想

维护区间 `[lo, hi]`，取中点 `mid` 判断：若 `a[mid]` 满足条件则缩右端，否则缩左端，直到 `lo == hi`。

## 算法流程

1. 初始化 `lo = 0, hi = n`（注意 `hi` 取 `n` 而非 `n-1`）
2. 循环 `lo < hi`：取 `mid = (lo + hi) / 2`
3. 若 `a[mid] < x`：`lo = mid + 1`（目标在右半）
4. 否则：`hi = mid`（目标在左半含 mid）
5. 循环结束时 `lo == hi` 即为答案位置

**答案二分**：将 `check(mid)` 替换 `a[mid] < x` 的判断即可。

## 复杂度

- 时间：O(log n)
- 空间：O(1)
