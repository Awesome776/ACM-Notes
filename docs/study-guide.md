## 竞赛模板编写规范

本仓库的模板遵循以下规范：

1. **文件头注释**：标注算法名称、时间/空间复杂度、功能说明
2. **完整可编译**：每个 `.cpp` 文件都含 `main` 函数，可直接编译运行
3. **中文注释**：关键逻辑用中文注释说明
4. **快读优化**：使用 `ios::sync_with_stdio(false); cin.tie(nullptr);`
5. **命名规范**：数组用 `MAXN` 定义上界，变量名清晰可读

## 笔记编写规范

1. **Markdown 格式**：使用标准 Markdown，支持 LaTeX 公式
2. **结构清晰**：概述 → 算法讲解 → 代码 → 例题 → 总结
3. **关联模板**：在笔记中链接对应的模板文件
4. **持续更新**：学习新知识点后及时补充
